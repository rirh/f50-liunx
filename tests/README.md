# Tests

```sh
python3 -m unittest discover -s tests            # everything this machine can run
F50_TEST_SHELLS="busybox sh" python3 -m unittest discover -s tests   # one shell only
python3 -m unittest $(cd tests && python3 shard.py 4 0)      # what CI shard 0 of 4 runs; PRs add F50_TEST_SHELLS="busybox sh" (quick mode)
```

Standard library only (`lz4`, the command or `pip install lz4`, for the boot image tests). Upstream's CI runs them on Ubuntu and macOS.

The device scripts run under dash (Ubuntu's `/bin/sh`), bash and busybox ash (OpenWrt); every shell test runs under
each of them that is installed. Commands that touch the device (`nft`, `ip`, `id`, `sing-box`) are stubs, and the
scripts read a fake `/` through `F50_SYSROOT`, `F50_DISK` and friends; `f50-update` is sourced
with `F50_LIB=1`, which defines its functions and runs nothing.
